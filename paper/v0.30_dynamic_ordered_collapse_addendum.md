## 1. Motivation

v0.29 showed that a collapse-containment overlay could drain the uncontained 617.87 Mpc mode after the v0.28 thermodynamic run. The next question was whether the same idea still works when applied in the correct order.

v0.30 therefore applies containment at each MCIFT response epoch before final scoring.

## 3. Dynamic ordered rule

For each response epoch:

```text
coherence_capacity = 3.5 n X_containment A_lock W_capture
contained_complexity_load = C_n (1 + theta_G + c_s^2)
collapse_pressure = max(0, contained_complexity_load / coherence_capacity - 1)
collapse_factor(lambda) = exp[-collapse_pressure * max(0,lambda/R_A - 1) * lambda/R_A]
B_next = B + leaked V/D contained-complexity excess
```

This differs from v0.29 because the spectrum is not corrected once at the end. The super-anchor mode is tested against containment at every response epoch before final scoring.
