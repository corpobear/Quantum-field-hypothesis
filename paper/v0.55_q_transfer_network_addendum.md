# v0.55 Q_i Transfer Network Addendum

**Status:** calibrated transfer-network scaffold; not established physics.

## Purpose

v0.55 implements a first Q_i transfer-network bridge for the coarse-grained cosmology layer. It compares raw v0.54 no-transfer expansion against a transfer-corrected background and a small set of real-world reference checkpoints.

## Continuity form

```text
dot(rho_i) + 3H(rho_i + p_i) = Q_i
sum_i Q_i = 0
```

## Simplified transfer map

```text
rho_i(today) = R_i rho_i(v0.54)
rho_smooth(today) = sum_i (1 - R_i) rho_i(v0.54)
```

## Interpretation

Raw v0.54 over-expands when local collision fractions are used directly as present-day cosmic densities. v0.55 shows that a transfer/smoothing network is required before real-world H(z) comparison.

## Limitation

This is calibrated to a Planck-like background. It is not yet a predictive cosmology fit. DESI-style evolving-dark-energy behavior is not fitted in this version.
