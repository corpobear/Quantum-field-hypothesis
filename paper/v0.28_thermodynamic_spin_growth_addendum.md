## 2. No-fit thermodynamic closure

v0.28 defines the thermal layer from existing channel loads:

```text
rho_G      ~ A + 0.6 V + 0.45 D + exchange
rho_T      = R
theta_T    = rho_R / (rho_R + rho_G)
T_rel      = theta_T^(1/4)
beta_T     = sqrt(T_rel)
W_capture  = 4(1-exp[-beta_T^2]) exp[-beta_T^2]
c_s^2      = beta_T^2 / 3
chi_thermo = chi_MGT * (1 + beta_T)
N_eff      = 4 + 2 exp[-chi_thermo^2]
```

No parameter sweep was used. The capture-window factor `4` is the analytic normalization of `(1-e^-x)e^-x`, whose maximum is `1/4`.

## 3. Physical interpretation inside MCIFT

The thermodynamic layer adds the following internal feedback:

```text
radiation-like channel R
-> thermal fraction theta_T
-> relative temperature T_rel
-> thermal speed beta_T
-> capture/scattering window W_capture
-> sound-speed proxy c_s^2
-> stronger spin blur chi_thermo

```

This implements the idea that temperature, speed, and time response affect the knot's ability to resolve its internal dark sectors.

## 7. Remaining failure

The unresolved issue is not the sink count alone. v0.26-v0.28 all support a six-internal-to-four-effective sink projection. The remaining issue is the background growth/conservation law.

The next necessary equations are:

```text
d rho_A / d ln a = -Q_A_to_V - Q_A_to_D
d rho_V / d ln a =  Q_A_to_V - Q_V_to_D - Q_V_to_R
d rho_D / d ln a =  Q_A_to_D + Q_V_to_D
d rho_R / d ln a =  Q_V_to_R
```

Then the no-fit thermodynamic perturbation layer should be rerun on the conserved channel backgrounds instead of milestone snapshots.
