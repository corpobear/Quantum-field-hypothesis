Earlier MCIFT cosmology runs showed a persistent pattern:


## 3. Internally constrained thermodynamic closure

v0.28 defines the thermal layer from existing channel loads:

```text
rho_G      ~ A + 0.6 V + 0.45 D + exchange
rho_T      = R
theta_T    = rho_R / (rho_R + rho_G)
T_rel      = theta_T^(1/4)
beta_T     = sqrt(T_rel)
W_capture  = 4(1-exp[-beta_T^2]) exp[-beta_T^2]
c_s^2      = beta_T^2 / 3
chi_thermo = chi_MGT * (1 + beta_T)
N_eff      = 4 + 2 exp[-chi_thermo^2]
```

The capture-window factor `4` is the analytic normalization of `(1-e^-x)e^-x`, whose maximum is `1/4`. It is not a swept/fitted coefficient, but the closure itself remains heuristic.

## 4. Physical interpretation inside MCIFT

The thermodynamic layer adds the following internal feedback:

```text
radiation-like channel R
-> thermal fraction theta_T
-> relative temperature T_rel
-> thermal speed beta_T
-> capture/scattering window W_capture
-> sound-speed proxy c_s^2
-> stronger spin blur chi_thermo
-> effective sink count N_eff
-> modified native growth
```

This implements the idea that temperature, speed, and time response affect the knot's ability to resolve its internal dark sectors.

## 7. Meaning of the result

The v0.28 run is stronger than the v0.23-v0.27 native-growth sequence because it improves the shape score without importing a standard growth-transfer curve and without a parameter sweep.

However, it is not a complete cosmology result.

Safe statement:


Unsafe statement:
