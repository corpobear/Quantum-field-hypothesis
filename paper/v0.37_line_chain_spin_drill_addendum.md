# Addendum v0.37: Line-Chain Spin-Drill Higgs Test

**Status:** speculative collider-style toy test; not established physics.  
**Scope:** connect cube centers in a straight line, drive opposite information/phase flows, measure spin/twist over time, and test whether a localized dent/drill/sink forms.

---

## 1. Purpose

v0.37 converts the cube-center and Higgs-vortex idea into a minimal line-chain collision-style test.

```text
cube center -> cube center -> cube center -> collision center <- cube center <- cube center
```

The test asks whether accumulated phase spin and local twist can create a localized sink near the collision center.

---

## 2. Math under test

For center phases `phi_i(t)`:

```text
delta_phi_i = phi_(i+1) - phi_i
omega_i = d(delta_phi_i)/dt
Theta_i = phi_(i+1) - 2 phi_i + phi_(i-1)
```

Connector compatibility:

```text
A_i = sqrt(a_i a_(i+1))
chi_i = A_i P_phase P_timing P_match
P_phase = cos^2(delta_phi_i)
P_timing = exp[-omega_i^2 / omega_0^2]
P_match = exp[-(K_(i+1)-K_i)^2 / sigma_K^2]
```

Face-plane vortex and mass:

```text
Omega_i = H_i sigma(chi_i - chi_c)
m_i = m_scale Omega_i A_i
```

Dent / drill / sink load:

```text
D_i = alpha_spin |omega_i| + alpha_twist |Theta_i| + alpha_Omega Omega_i
S_i = Coh_i - q_i - D_i
dB_i/dt = gamma_B max(0,-S_i) - decay_B B_i
```

Sink condition:

```text
S_i < 0
```
