# Addendum v0.31: Cube-Center Six-Connector Knot Geometry

**Status:** speculative paper-style geometry addendum; not established physics.  
**Scope:** introduces the cube-center six-connector knot picture as the current conceptual geometry layer for MCIFT.

---

## 1. Core geometry

A knot is placed at the center of a spacetime cube-cell:

```text
knot position = center of cube-cell
```

It has six axial connector directions through the cube faces:

```text
+x, -x, +y, -y, +z, -z
```

Each connector links the center of one cube-cell to the center of a neighboring cube-cell.

Each connector can be inactive, partially active, or fully active:

```text
0 <= a_mu <= 1
```

where:

```text
a_mu = 0   inactive
a_mu = 1   fully active
0<a_mu<1   partially active
```

---

## 2. Six connector states

For a knot `i`, define:

```text
a_i,+x
a_i,-x
a_i,+y
a_i,-y
a_i,+z
a_i,-z
```

The total connector activation is:

```text
A_i,total = sum_mu a_i,mu
```

The mean activation is:

```text
a_i,mean = (1/6) sum_mu a_i,mu
```

---

## 3. Directional balance

Opposite connectors stabilize the knot when they balance.

```text
Delta_i = sqrt[(a_+x-a_-x)^2 + (a_+y-a_-y)^2 + (a_+z-a_-z)^2]
```

Balanced cube-center containment:

```text
a_+x = a_-x
a_+y = a_-y
a_+z = a_-z
Delta_i = 0
```

A large imbalance means the knot is strained away from centered containment.

---

## 4. Coherence capacity

The six connectors supply local coherence capacity:

```text
Coh_i = 6 a_i,mean - lambda_Delta Delta_i
```

A balanced knot has:

```text
Coh_i = 6 a_i,mean
```

An imbalanced knot has:

```text
Coh_i < 6 a_i,mean
```

---

## 5. Contained complexity and collapse

Let the knot contain internal complexity:

```text
Q_i
```

The basic containment condition is:

```text
coherence capacity >= contained complexity
```

or:

```text
S_i = Coh_i - Q_i
```

Stable/open knot:

```text
S_i >= 0
```

Containment failure:

```text
S_i < 0
```

Plain statement:

```text
A collapsed-knot sink forms when the coherence supplied by the six connector anchors is not enough to contain the complexity held by the knot.
```

## 7. Neighbor coupling

For neighboring cube-center knots `i` and `j`, a shared connector can be represented as:

```text
A_ij = sqrt(a_i,mu a_j,-mu)
```

If either side is inactive:

```text
A_ij = 0
```

If both sides are fully active:

```text
A_ij = 1
```

If one or both sides are partial:

```text
0 < A_ij < 1
```

## 8. Six sectors and projected channels

The cube-center geometry naturally gives six internal axial connector sectors:

```text
+x, -x, +y, -y, +z, -z
```

In a rotating or projected system, not all six internal directions need remain separately resolved. Depending on anchor-axis selection and spin blur, the observable transverse response can reduce toward four effective transverse channels.

This supports the distinction:

```text
six internal connector sectors
```
