# v0.49 Core Load Feedback Addendum

**Status:** speculative MCIFT scaffold addendum; not established physics.

## Purpose

This addendum documents the v0.49 correction: hidden/sink matter is computed separately from visible matter during entanglement, but still feeds back into the rotating core as a compact local load.

## New relation

```text
G_visible = E_visible_pool
G_hidden = C_sink * E_hidden_sink
G_rot = xi_rot * E_rotation_bound
G_load = G_visible + G_hidden + G_rot
```

The load then changes the core pressure through a support/load feedback:

```text
capacity_after_feedback = capacity_before_feedback + confinement_gain
core_load_after_feedback = core_load_before_feedback + pressure_penalty
core_pressure_after_feedback = core_load_after_feedback / capacity_after_feedback
```

## Interpretation

The hidden branch is not projected into visible channels. It becomes a separate local load on the rotating core. In the v0.49 toy run, the hidden feedback strengthens the core load but also increases support enough to keep the pressure below capacity.
