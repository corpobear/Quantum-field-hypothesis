# MCIFT Applications

This folder contains practical, experimental utilities inspired by the MCIFT math layers.

The applications are not physics validations and do not claim that MCIFT replaces established image processing, quantum field theory, general relativity, the Standard Model, or standard cosmology. They are useful scripts that expose tunable numerical techniques derived from the repository's speculative scaffold.

## Current applications

```text
image_upscaling/    Bubble Inflation Upscaler
```

## Design rules

Applications in this folder should:

```text
1. State what they do in practical terms.
2. Keep MCIFT-inspired assumptions visible and adjustable.
3. Expose parameters rather than hiding magic constants.
4. Save optional debug/intermediate outputs when useful.
5. Avoid overclaiming: generated detail is enhancement, not recovered ground truth.
```
