## Generate visuals

Run from the repository root:

```bash
python mechanics/plot_mechanics.py
```

The script generates SVG diagrams for:

```text

field-source pipeline
funnel-speed capture window
fourth-mode reservoir gate
eight-sector knot/shadow sink geometry
dark-visible ratio comparison
mechanics overview
```

The main mechanics file references these generated SVG paths.
