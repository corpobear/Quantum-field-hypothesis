# Predictions and Falsifiability Notes

## Status

MCIFT is currently a speculative toy field framework. Its claims are not yet precision predictions of confirmed physics. The goal is to turn structural predictions into testable mathematical predictions.

## Current model predictions

### 1. No stable fourth charged-lepton-like generation

The toy model predicts three stable modes and fourth-mode failure.

Using:

```math
C_n=2^n
```

and:

```math
S_n=an-2^n
```

three stable modes and fourth failure occur when:

```math
\frac{8}{3}<a<4
```

If a stable fourth charged-lepton-like generation were confirmed, the model would be under serious pressure.

### 2. Mass begins at the cluster level

The model predicts that isolated information-cells have almost no mass. Rest mass begins only when information forms coherent clusters capable of receiving finite Higgs response.

### 3. Heavier generations should be closer to instability

The model expects:

```text
electron-like mode: most stable
muon-like mode: less stable
tau-like mode: closer to failure
fourth mode: fails as a localized generation
```

### 4. Higgs response should be finite

The Higgs response is modeled as a window, not an infinite growth mechanism:

```math
H(C_n)=e^{-\frac{(C_n-C_\star)^2}{2\sigma_H^2}}
```

or log-fractal:

```math
H(C_n)=e^{-\frac{(\ln C_n-\ln C_\star)^2}{2w^2}}
```

### 5. Channel transfer should depend on compatibility

Transfer between channels should be strongest when coherence is high and complexity/mass mismatch is small:

```math
T_{i\rightarrow s}
=
Q_iQ_s
e^{-\frac{(C_i-C_s)^2}{2\sigma_C^2}}
e^{-\frac{(m_i-m_s)^2}{2\sigma_m^2}}
```

### 6. Black holes suppress external channel transfer

A black hole is modeled as an internal-channel confinement region:

```math
T_{BH\rightarrow outside}\approx 0
```

## Near-term test target

The best next target is the charged lepton mass sequence.

Research goal:

```text
Use electron and muon masses to predict tau mass
with as few adjustable parameters as possible.
```

If tau can be predicted accurately from locked assumptions, the framework becomes much more interesting.

## Current limitation

The framework can fit or approximate mass patterns using adjustable parameters, but a fit is not yet a prediction. A serious prediction requires locking:

- complexity law,
- coherence law,
- fractal dimension,
- Higgs response center and width,
- channel-transfer rule.

## Falsifiability direction

The model becomes falsifiable when it makes fixed numerical claims, such as:

- exact tau mass from electron and muon inputs,
- absence of a fourth stable charged generation,
- relationship between decay instability and cluster stability,
- specific deviations in Higgs coupling behavior,
- measurable signatures of finite Higgs response.
